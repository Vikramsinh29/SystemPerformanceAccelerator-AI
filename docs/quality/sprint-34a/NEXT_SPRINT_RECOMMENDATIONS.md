# Next Sprint Recommendations

## Recommended next sprint

**Sprint 34B — Compatibility and Benchmark Evidence Foundation**

Keep the scope narrow:

- compatibility result model
- Markdown and machine-readable Windows test matrix
- benchmark result model
- median, minimum, maximum, and variability calculations
- invalidation rules for materially different conditions
- raw evidence folder conventions
- controlled end-to-end benchmark procedure
- calculation and serialization tests

## Do not combine into 34B

- remote telemetry
- Store publishing
- licensing
- recommendation redesign
- false-positive dashboard
- automatic performance claims

## Following sprint

**Sprint 34C — Recommendation Evidence and False-Positive Control**

Add stable rule IDs, rule versions, categorical confidence, risk, reversibility, ground-truth cases, precision/recall calculations, and regression tests.
