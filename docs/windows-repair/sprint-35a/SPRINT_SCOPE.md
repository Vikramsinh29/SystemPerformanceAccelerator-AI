# Sprint 35A Scope

Sprint 35A adds a read-only Windows Repair Assessment module.

Included:

- environment preflight
- DISM CheckHealth
- SFC VerifyOnly
- safe sequential execution
- stop-after-current behaviour
- sanitized local history
- manual report export
- retention and deletion
- automated and manual verification

Excluded:

- every repair command
- CHKDSK
- reboot handling
- component cleanup
- registry repair
- remote telemetry
- performance improvement claims
